# Admin Tampermonkey Scripts

Updater installer links:

```text
Ricochet Spam Guru Risk Ratings Updater
https://raw.githubusercontent.com/ugomez809/GIA-TamperMonkey/main/Admins/Spam%20Guru%20Risk%20Ratings/ricochet-spam-guru-risk-ratings-updater.user.js
```

Install only the updater. The updater fetches, caches, and runs the matching admin script from this folder.

Direct script links:

```text
Ricochet Spam Guru Risk Ratings
https://raw.githubusercontent.com/ugomez809/GIA-TamperMonkey/main/Admins/Spam%20Guru%20Risk%20Ratings/ricochet-spam-guru-risk-ratings.user.js
```

Spam Guru Risk Ratings adds a small toggle on the Ricochet Spam Guru config page to visually reveal Hiya and TNS risk labels currently hidden behind RMD without changing the Remediate value.
